# Features

Everything Fluxion does right now, as tables. Yes / partly / no first, the other stuff after.

| Feature                                  |        |
| ---------------------------------------- | ------ |
| Polynomial equations                     | yes    |
| Exact cubics                             | yes    |
| Complex roots                            | yes\*  |
| Literal equations                        | yes    |
| Exp, log and root equations              | yes    |
| Absolute value equations                 | yes    |
| Rational equations                       | yes    |
| Trig equations                           | yes    |
| Inequalities                             | yes\*  |
| Numeric roots, no exact form (6 digits)  | yes\*  |
| Solve steps                              | yes\*  |
| Steps for expand, factor, simplify       | yes\*  |
| Steps for derivatives, limits, integrals | yes\*  |
| Working folds away on long step pages    | yes\*  |
