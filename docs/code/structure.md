# Structure

## File layout

```
fluxion/
├── makefile    calculator build (CEdev), compressed to one .8xp
├── pc.makefile    PC build: engine, tools, the app in a window; `make -f pc.makefile test`
├── icon.png
├── src/
│   ├── main.c  calculator start: app_run()
│   ├── main_pc.c  the same app on the PC (window, or scripted keys -> PNG)
│   ├── engine/   PineappleCAS engine (MIT, see its README for what's changed)
│   │   ├── cas/   simplify, expand, factor, derivative, identities, solve (+ trig families, systems in system.c), asym, approx (decimal), degrees
│   │   ├── imath/  big-number + rational maths
│   │   └── pc/  PC-only command line + test runner (empty on the calculator)
│   ├── platform/  screen.h / keys.h / store.h: *_ti.c = graphx + keypadc + appvars, *_pc.c = framebuffer + SDL + files in build-pc/store
│   ├── render/
│   │   ├── layout.c    expression tree -> boxes with sizes + positions (no drawing)
│   │   ├── draw.c  boxes -> lines and text, through screen.h
│   │   └── fonts.c   bitmap fonts (generated by tools/bdf2c.py)
│   ├── editor/
│   │   └── editor.c    the input line: rows, templates, cursor; to engine string / boxes
│   └── ui/
│       ├── app.c    history, input line, soft-key folders, running the engine
│       ├── catalog.c  everything you can type or pick, and what the engine can do. its words are the name table too
│       ├── page.c  full screen list pages (catalog, vars, mode)
│       ├── names.c  stored names and the typed-word lookup the editor asks
│       ├── vars.c   the [vars] page
│       ├── mode.c  the [mode] page
│       └── settings.c  the angle mode, and saving the lot
├── test/
│   ├── pcas.tests   PineappleCAS's 256 engine tests
│   ├── fluxion.tests   Fluxion's engine tests (factor, solve, cancel, roots, forms)
│   ├── identity_masks.c   checks the identity skip is safe
│   ├── layout_dump.c   prints the box tree: ./build-pc/layout-dump '(X+1)^2/X'
│   ├── view.c  draws expressions: ./build-pc/view --png out.png 'X^2/2'
│   └── editor_test.c   editor steps -> picture: ./build-pc/editor-test t:2 frac t:1
└── docs/
```

only `src/platform/` is allowed to touch graphx, keypadc or SDL. everything else is the same code on the PC and the calculator, so i can test basicly all of it on the PC without the emulator

## Testing

- PC: engine + layout built with `gcc`, takes a few seconds
- CEmu: by hand. `cemu-autotester` comes with CEdev if i ever want scripted key presses

## Gotchas

- CEmu + relative paths: `-s bin/FLUXION.8xp` silently does nothing if CEmu is already open from another folder. use the full path (VS Code configs use `${workspaceFolder}`)
- IntelliSense thinks `int` is 32-bit, it's 24-bit on the eZ80. trust the compiler not the editor
- `make debug` right after a normal build says "nothing to be done", `make clean` first
- over 64 KB the toolchain splits it into a launcher + appvars (3 files to send), `COMPRESSED = YES` keeps it as one `.8xp`
- engine syntax: capital single letter variables, `_` is subtract, `-` is negate (TI style)
