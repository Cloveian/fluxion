Install

  1. If you're on OS 5.5 or newer, jailbreak it with arTIfiCE, and get a shell like Cesium.
  2. Send the CE C libraries (clibs.8xg).
  3. From releases, send Fluxion-app.b84 with TI Connect CE, then run FLUXINST once. Fluxion shows up under apps.

Made by Cloveian. The math engine started as PineappleCAS by Nathan Farlow, big numbers are imath, the installer is CEaShell's, and the keypad up there was measured off CEmu's.
